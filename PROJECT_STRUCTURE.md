## 🚀 Quick Reference

### Run Everything
```bash
# 1. Setup
pip install -r requirements.txt
python scripts/setup_database.py

# 2. Analysis
python notebooks/eda/01_exploratory_data_analysis.py
python notebooks/feature_engineering/01_feature_engineering.py
python notebooks/ml/01_machine_learning_models.py

# 3. Visualizations
python scripts/generate_visualizations.py
```

### Key Outputs
- Database: `data/sql/ecommerce.db`
- Processed Data: `data/processed/*.csv`
- Models: `models/*.pkl`
- Reports: `reports/*.png` and `reports/executive_summary.md`
- Dashboard Templates: `dashboard/*.md`
