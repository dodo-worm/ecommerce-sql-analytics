# Dashboard Folder

This folder contains templates and guides for creating analytics dashboards using Power BI or Tableau.

## 📁 Contents

### Files

1. **powerbi_template.md**
   - Complete Power BI dashboard template
   - DAX measures and calculations
   - Data model and relationships
   - Visual layouts and configurations
   - Deployment instructions

2. **tableau_template.md**
   - Complete Tableau dashboard template
   - Calculated fields and LOD expressions
   - Data source connections
   - Visual layouts and color palettes
   - Publishing and optimization tips

## 🎯 Dashboard Pages

Both templates include 5 dashboard pages:

1. **Executive Summary**
   - KPI cards (Revenue, Orders, Customers, AOV)
   - Revenue trend chart
   - Order volume chart
   - Customer growth chart

2. **Customer Analytics**
   - Customer segmentation (RFM)
   - Customer retention rate
   - Churn risk analysis
   - Top customers table

3. **Product Performance**
   - Top products by revenue
   - Top products by quantity
   - Category performance
   - Low stock alerts

4. **Sales Trends**
   - Monthly revenue trend
   - Revenue by category
   - Orders by day/hour
   - Average order value trend

5. **Regional Analysis**
   - Sales by state (map)
   - Sales by city
   - Regional customer distribution
   - Top products by region

## 🚀 Getting Started

### Power BI

1. Open Power BI Desktop
2. Follow the template in `powerbi_template.md`
3. Connect to your data source
4. Create the calculated measures
5. Build the visualizations
6. Publish to Power BI Service

### Tableau

1. Open Tableau Desktop
2. Follow the template in `tableau_template.md`
3. Connect to your data source
4. Create the calculated fields
5. Build the visualizations
6. Publish to Tableau Server/Online
